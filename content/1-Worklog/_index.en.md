This worklog summarizes the learning activities and tasks recorded across ten weeks of the First Cloud AI Journey (FCAJ) internship report. It is organized into two phases: learning AWS fundamentals and studying and developing the **Driver Drowsiness & Distraction Detection** project, which combines Edge AI with AWS Cloud.

## Overview of 10 weeks

**Week 1:** [Introduction to FCAJ, cloud computing, and core AWS services](1.1-week1/)

**Week 2:** [Identity and access management with IAM and Amazon VPC networking](1.2-week2/)

**Week 3:** [Exploring EC2, EBS, S3, RDS, and DynamoDB](1.3-week3/)

**Week 4:** [Scalability, monitoring, and serverless architecture](1.4-week4/)

**Week 5:** [Exploring IaC, CI/CD, containers, data analytics, and AI/ML on AWS](1.5-week5/)

**Week 6:** [Driver drowsiness and distraction analysis and Edge AI architecture design](1.6-week6/)

**Week 7:** [Image-processing pipeline with OpenCV, MediaPipe, and facial features](1.7-week7/)

**Week 8:** [AWS backend integration and event metadata processing](1.8-week8/)

**Week 9:** [Dashboard, Cognito authentication, access control, and monitoring](1.9-week9/)

**Week 10:** [Project documentation, bilingual proposal, and architecture diagram](1.10-week10/)

## Summary

The first five weeks focus on cloud computing, security, networking, storage, databases, and AWS services. The following weeks focus on driver monitoring, on-device image processing, backend architecture, authentication, and project documentation. Each weekly entry presents the corresponding objectives, tasks, and outcomes.

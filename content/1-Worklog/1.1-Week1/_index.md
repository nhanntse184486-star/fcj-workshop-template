### Week 1 Objectives:

* Get familiar with the First Cloud AI Journey (FCAJ) internship program, its learning structure, reporting requirements, and expected outcomes.
* Understand fundamental Cloud Computing concepts, deployment models, and service models.
* Explore Amazon Web Services (AWS) and the main categories of cloud services.
* Understand AWS Global Infrastructure, including Regions, Availability Zones, and Edge Locations.
* Become familiar with the AWS Management Console, AWS CloudShell, and AWS Command Line Interface (CLI).
* Learn about AWS account security, billing management, AWS Budgets, and the Shared Responsibility Model.
* Build a foundation for more advanced AWS networking and application deployment topics.

### Week 1 Achievements:

* Developed a foundational understanding of Cloud Computing and its role in modern IT infrastructure.
* Learned the differences between cloud service models:
  * Infrastructure as a Service (IaaS).
  * Platform as a Service (PaaS).
  * Software as a Service (SaaS).
* Understood fundamental cloud characteristics, including:
  * On-demand resource provisioning.
  * Elasticity and scalability.
  * High availability.
  * Usage-based pricing.
* Became familiar with the AWS Global Infrastructure and the purpose of Regions and Availability Zones.
* Explored the AWS Management Console and learned how AWS services are organized.
* Studied the purpose of AWS CloudShell and AWS CLI in managing cloud resources.
* Learned about AWS account security, AWS Budgets, and cost monitoring.
* Understood the AWS Shared Responsibility Model and the difference between security of the cloud and security in the cloud.
* Improved technical reading skills and developed an initial understanding of AWS documentation.

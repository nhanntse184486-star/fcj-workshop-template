### Week 3 Objectives:

* Understand Amazon Elastic Compute Cloud (EC2) and virtual server deployment.
* Learn about Amazon Machine Images (AMI), EC2 Instance Types, and instance lifecycle management.
* Study Amazon Elastic Block Store (EBS) and EBS Snapshots.
* Explore Amazon Simple Storage Service (S3) and object storage.
* Understand Amazon Relational Database Service (RDS).
* Learn the basic concepts of Amazon DynamoDB and NoSQL databases.
* Compare different compute, storage, and database solutions based on application requirements.
* Understand basic resource management and cost considerations.

### Week 3 Achievements:

* Developed an understanding of Amazon EC2 and the role of virtual servers in cloud computing.
* Studied core EC2 concepts, including:
  * Instance Types.
  * Amazon Machine Images.
  * Key Pairs.
  * Security Groups.
  * Instance lifecycle states.
* Understood the purpose of Amazon EBS, including persistent storage volumes and snapshots.
* Learned the differences among major AWS storage models:
  * Amazon S3 for object storage.
  * Amazon EBS for block storage.
  * Amazon EFS for shared file storage.
* Studied Amazon S3 features such as Versioning, Storage Classes, and Lifecycle Policies.
* Learned about Amazon RDS and managed relational database operations.
* Developed a basic understanding of Amazon DynamoDB and NoSQL data models.
* Understood how applications can combine compute, object storage, and databases.
* Improved the ability to select AWS services based on technical requirements and expected cost.
* Established the foundational knowledge needed to explore highly available and serverless architectures.

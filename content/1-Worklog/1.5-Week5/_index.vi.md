### Mục tiêu tuần 5:

* Tổng hợp và củng cố những kiến thức AWS đã nghiên cứu trong bốn tuần trước.
* Tìm hiểu Infrastructure as Code (IaC) và các phương pháp tự động hóa việc quản lý hạ tầng.
* Nghiên cứu AWS CloudFormation và AWS Cloud Development Kit (CDK).
* Tìm hiểu CI/CD Pipeline và những nguyên tắc DevOps trên AWS.
* Nghiên cứu Docker, Amazon ECS, Amazon EKS và AWS Fargate.
* Tìm hiểu các dịch vụ Data Analytics trên AWS và kiến trúc Data Processing.
* Nghiên cứu Machine Learning và Generative AI trên AWS.
* Tìm hiểu Amazon SageMaker, Amazon Bedrock, Foundation Model, Prompt Engineering và Retrieval-Augmented Generation (RAG).
* Xác định những dịch vụ AWS có thể sử dụng trong dự án cuối kỳ.

### Kết quả đạt được tuần 5:

* Củng cố kiến thức nền tảng về Compute, Networking, Storage, Database và Security trên AWS.
* Hiểu khái niệm Infrastructure as Code và lợi ích của việc tự động triển khai hạ tầng.
* Nắm được chức năng cơ bản của AWS CloudFormation và AWS CDK.
* Tìm hiểu DevOps, CI/CD Pipeline và quá trình tự động hóa triển khai ứng dụng.
* Nghiên cứu các công nghệ Container:
  * Docker.
  * Amazon ECS.
  * Amazon EKS.
  * AWS Fargate.
* Hiểu được khái niệm Data Lake và các bước cơ bản trong Data Processing.
* Tìm hiểu AWS Glue, Amazon Athena và Amazon QuickSight.
* Nghiên cứu quy trình Machine Learning:
  * Data Preparation.
  * Model Training.
  * Model Evaluation.
  * Model Deployment.
* Hiểu vai trò của Amazon SageMaker trong việc xây dựng và triển khai mô hình Machine Learning.
* Nắm được kiến thức tổng quan về Generative AI, Large Language Model và Foundation Model.
* Tìm hiểu Amazon Bedrock và các trường hợp ứng dụng Generative AI.
* Nghiên cứu Prompt Engineering và những yếu tố ảnh hưởng đến chất lượng phản hồi của mô hình.
* Hiểu kiến trúc RAG gồm:
  * Document Processing.
  * Text Chunking.
  * Embedding.
  * Vector Search.
  * Context Retrieval.
  * Response Generation.
* Tìm hiểu những nguyên tắc cơ bản của AI Agent và quy trình sử dụng công cụ.
* Xác định các dịch vụ AWS có khả năng hỗ trợ dự án cuối kỳ.
* Hoàn thành giai đoạn tổng hợp kiến thức nền tảng để chuẩn bị chuyển sang nghiên cứu và phát triển dự án.

### Week 5 Objectives:

* Consolidate the fundamental AWS knowledge acquired during the previous four weeks.
* Understand Infrastructure as Code (IaC) and automated infrastructure management.
* Learn about AWS CloudFormation and AWS Cloud Development Kit (CDK).
* Explore CI/CD pipelines and DevOps practices on AWS.
* Understand containerization and the fundamentals of Docker, Amazon ECS, Amazon EKS, and AWS Fargate.
* Explore AWS Data Analytics services and data processing architectures.
* Study the fundamentals of Machine Learning and Generative AI on AWS.
* Understand Amazon SageMaker, Amazon Bedrock, Foundation Models, Prompt Engineering, and Retrieval-Augmented Generation (RAG).
* Identify possible AWS technologies and research directions for the final internship project.

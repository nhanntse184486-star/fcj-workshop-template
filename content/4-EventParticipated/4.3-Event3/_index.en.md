# AWS Cloud and AI Day Hanoi 2026 – HCMC Watch Party

| Information | Details |

| Format | Live-streamed presentations and local networking |
| Role | Attendee |

## 2. Event Objectives

The watch party enabled the local community to follow technical sessions from Hanoi and explore the relationship between AI, cloud infrastructure and application modernization.

## 3. Key Highlights and Activities

### 3.1. Keynote and technology trends

The main program discussed how cloud and AI can support innovation, including the shift toward AI agents and scalable digital services.

### 3.2. Builders x AI

The technical track examined AI-assisted engineering, tool-enabled agents and cloud-native application development. These topics illustrated how developers can incorporate AI into multi-step workflows rather than treating it only as a conversational interface.

### 3.3. Application modernization

The program linked modernization to cloud migration, data foundations and automation, highlighting the relationship between infrastructure decisions and software capabilities.

### 3.4. Community networking

The local format offered opportunities for technical exchange among people interested in AWS and AI.

## 4. Knowledge and Key Takeaways

- AI-assisted development requires engineering judgment and careful evaluation of generated outputs.
- Cloud-native design supports flexible resource allocation and integration between application components.
- AI agents introduce additional considerations for access control, tool usage and workflow reliability.
- Community learning helps developers keep their technical knowledge up to date.

## 5. Relevance to the Internship Project

For my **Driver Drowsiness & Distraction Detection** project, the event's themes provide a useful framework for evaluating architectural choices.

| Lesson | Project application |
|---|---|
| Cloud-native design | Separate event ingestion, processing and storage with API Gateway, Lambda and DynamoDB. |
| Appropriate AI usage | Keep image inference on the edge device and transmit only necessary event metadata. |
| Software quality | Validate detection logic and API behavior before relying on AI-assisted development tools. |
| Security and reliability | Limit access to event data, monitor failures and consider retry mechanisms. |

The discussion of agentic AI offers a broader perspective on future AI systems; it does not imply that AI agents are part of the current project.

## 6. Conclusion

The watch party connected developments in AI with the practical responsibilities of cloud and software engineers. Its themes reinforce the value of selecting technology according to real application requirements and maintaining a reliable, secure system.
